# Dự án Website thương mại điện tử - VENZA (Dự án cá nhân)

## Giới thiệu 🎉

VENZA là Website bán mỹ phẩm trực tuyến và là một dự án Fullstack Web Application xây dựng trên nền tảng Node.js theo hướng Server-side rendering.

## Cài đặt & Triển khai ⬇️

1. Tải mã nguồn (Clone the Project) 💻

```bash
git clone "https://github.com/Danh13320031/WebApp-VENZACosmetic-Nodejs"
```

2. Thiết lập biến môi trường (Set Up Environment Variables) ⚙️
   Tạo một file .env tại thư mục gốc của dự án. Sau đó, cấu hình các thông số cần thiết (tham khảo file .env.example nếu có) như: Port, MongoDB URI, Gemini API Key, Session Secret...

3. Cài đặt các thư viện (Install Dependencies) 📦

```bash
npm install
```

4. Khởi chạy dự án (Start the Project) 🚀

```bash
npm start
```
